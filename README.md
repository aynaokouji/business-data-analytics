## 📊 Featured Projects

### 🛒 Supermarket Customer Churn Analysis

超市会员流失用户分析

使用决策树分析会员流失特征，比较不同树深度下模型结构，并提取主要流失路径。

### ☕ Coffee Price Sensitivity Analysis

手冲咖啡价格敏感度分析

使用 PSM 模型分析消费者对不同价格区间的接受程度，辅助新品定价决策。

### 🎓 University Brand Influence Dashboard

广西高校品牌影响力数据分析

通过媒体指标、搜索指标等数据，构建高校品牌影响力可视化大屏。

### 📱 Douyin Content Analysis

短视频内容策略分析

对抖音企业号评论数据进行清洗、情感分析，比较不同内容策略的用户反馈。
